# P0-DEPLOY-001-全站502服务不可用

## 问题描述
draw.todonot.com 全站所有页面返回 HTTP 502 Bad Gateway，服务完全不可用。Nginx 反向代理后端服务无响应。

## 影响范围
- 文件：Docker 容器 / Nginx 配置
- 模块：部署与基础设施
- 影响：全站不可用，所有功能测试被阻塞

## 复现步骤
1. 访问 https://draw.todonot.com/（或 /editor、/templates）
2. 页面显示 "Bad Gateway"
3. curl 确认 HTTP 状态码为 502

## 修复方案
1. 检查 Docker 容器运行状态（docker ps）
2. 检查 Nginx 反向代理上游配置
3. 重启容器或修复端口映射
